    **Part A: Add callbackUrl support to login page**

    The current login page hardcodes `callbackURL: '/dashboard'` and `router.push('/dashboard')`. Without callbackUrl support, unauthenticated users who click "Sign in to accept" on the invite page will be sent to /dashboard after login instead of back to the invite page. This silently breaks ORG-03 for unauthenticated users.

    1. Update `src/app/(auth)/login/page.tsx` to pass searchParams to SignInForm:
       ```typescript
       export default async function LoginPage({ searchParams }: { searchParams: Promise<{ callbackUrl?: string }> }) {
         const { callbackUrl } = await searchParams
         return <SignInForm callbackUrl={callbackUrl} />
       }
       ```

    2. Update `src/components/auth/sign-in-form.tsx`:
       - Add `callbackUrl?: string` to component props: `export function SignInForm({ callbackUrl }: { callbackUrl?: string })`
       - Compute redirect target: `const redirectTo = callbackUrl || '/dashboard'`
       - Replace `callbackURL: '/dashboard'` with `callbackURL: redirectTo` in both `authClient.signIn.email()` and `authClient.signIn.social()`
       - Replace `router.push('/dashboard')` with `router.push(redirectTo)` in the onSubmit success handler
       - Security: Do NOT allow arbitrary external URLs. Validate that callbackUrl starts with `/` (relative path only):
         ```typescript
         const redirectTo = callbackUrl && callbackUrl.startsWith('/') ? callbackUrl : '/dashboard'
         ```

    **Part B: Create invitation accept page**

    Create `src/app/invite/[invitationId]/page.tsx` — a Server Component on a public route.

    This page must NOT use `verifySession()` (which redirects to /login). Instead, use `auth.api.getSession()` directly to check session without redirecting.

    ```typescript
    import { auth } from '@/lib/auth'
    import { prisma } from '@/lib/db'
    import { headers } from 'next/headers'
    import { Card, CardContent, CardDescription, CardHeader, CardTitle } from '@/components/ui/card'
    import { AcceptInvitationClient } from './accept-client' // client component for the accept button
    ```

    Page logic:
    1. Get invitationId from params: `const { invitationId } = await params`
    2. Fetch invitation from DB:
       ```typescript
       const invitation = await prisma.invitation.findUnique({
         where: { id: invitationId },
         include: { organization: { select: { name: true, slug: true } } },
       })
       ```
    3. If no invitation found: render expired/invalid state
    4. Check invitation status and expiry:
       - If `invitation.status !== 'pending'`: show "This invitation link has already been used or has expired."
       - If `invitation.expiresAt < new Date()`: show expired state
    5. Try to get session (without redirect):
       ```typescript
       const session = await auth.api.getSession({ headers: await headers() })
       ```
    6. If invitation is valid:
       - If no session: show "Sign in to accept" button that links to `/login?callbackUrl=/invite/${invitationId}`
       - If session exists:
         - Check if user is already a member: `const existingMember = await prisma.member.findFirst({ where: { userId: session.user.id, organizationId: invitation.organizationId } })`
         - If already member: show "You're already a member of {org name}." + "Go to workspace" link to `/${invitation.organization.slug}`
         - Otherwise: render `<AcceptInvitationClient invitationId={invitationId} orgName={invitation.organization.name} orgSlug={invitation.organization.slug} />`

    **Create `src/app/invite/[invitationId]/accept-client.tsx`** — `'use client'` component:
    - Props: `{ invitationId: string; orgName: string; orgSlug: string }`
    - Renders "Accept Invitation" primary button
    - On click:
      - Set loading state (`aria-busy={true}`, disabled)
      - Call `acceptInvitationAction(invitationId)` from `@/lib/actions/org-actions`
      - On success: `router.push(`/${orgSlug}`)`
      - On error: show error message inline

    **Page layout** — centered card matching auth page visual language:
    ```tsx
    <div className="flex min-h-screen items-center justify-center bg-background px-4">
      <Card className="w-full max-w-md">
        <CardHeader className="text-center">
          <CardTitle className="text-xl font-semibold">{title}</CardTitle>
          <CardDescription>{description}</CardDescription>
        </CardHeader>
        <CardContent className="flex flex-col items-center gap-4">
          {/* CTA button */}
        </CardContent>
      </Card>
    </div>
    ```

    **States and copy (from UI-SPEC):**
    - Valid + not signed in: Title "You've been invited", Description "Join {org name} on Notely.", CTA "Sign in to accept" linking to `/login?callbackUrl=/invite/${invitationId}`
    - Valid + signed in: Title "You've been invited", Description "Join {org name} on Notely.", CTA "Accept Invitation" (primary button)
    - Expired/used: Title "Invitation expired", Description "This invitation link has already been used or has expired."
    - Already member: Title "Already a member", Description "You're already a member of {org name}.", CTA "Go to workspace" linking to `/${orgSlug}`
    - Not found: Title "Invitation not found", Description "This invitation link is invalid."

    **Important:** The `/invite` route is already in `PUBLIC_ROUTES` in proxy.ts (from Plan 01), so unauthenticated users can reach this page.
