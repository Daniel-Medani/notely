  <action>
    1. Install use-debounce: `npm install use-debounce`

    2. Create `src/components/workspace/search-palette.tsx` as a `'use client'` component:

       **Imports:**
       - `useState`, `useEffect`, `useCallback`, `useRef` from `react`
       - `useDebouncedCallback` from `use-debounce`
       - `useRouter` from `next/navigation`
       - `Dialog`, `DialogContent` from `@/components/ui/dialog`
       - `Input` from `@/components/ui/input`
       - `Skeleton` from `@/components/ui/skeleton`
       - `Search`, `FileText` from `lucide-react`
       - `useWorkspace` from `@/components/workspace/workspace-layout`
       - `searchPagesAction` from `@/lib/actions/search-actions`
       - `SearchResult` type from `@/repositories/interfaces/ISearchRepository`

       **Props interface:**
       ```typescript
       interface SearchPaletteProps {
         open: boolean
         onOpenChange: (open: boolean) => void
       }
       ```

       **State:**
       - `query: string` (controlled input)
       - `results: SearchResult[]` (from server action)
       - `loading: boolean` (debounce in-flight)
       - `error: string | null` (from ActionResult error)
       - `highlightedIndex: number` (keyboard navigation, default -1)

       **Cmd+K listener:** NOT inside this component — the listener lives in the Sidebar which controls the `open` state. SearchPalette receives `open` and `onOpenChange` as props.

       **Debounced search:**
       - Use `useDebouncedCallback` with 300ms delay
       - If query length < 2, set results to [], loading to false, return early
       - Set loading true before calling `searchPagesAction({ query, organizationId })`
       - On result: if `result.success`, set results to `result.data`; otherwise set error to `result.error`
       - Set loading false after

       **Input onChange handler:**
       - Update query state immediately (controlled input)
       - Set loading true (optimistic loading state)
       - Call debounced search function
       - Reset highlightedIndex to -1

       **Keyboard navigation (onKeyDown on DialogContent):**
       - `ArrowDown`: increment highlightedIndex (mod results.length), prevent default
       - `ArrowUp`: decrement highlightedIndex (mod results.length), prevent default
       - `Enter`: if highlightedIndex >= 0 and results[highlightedIndex] exists, navigate to `/${orgSlug}/${results[highlightedIndex].id}` using `router.push`, close dialog

       **Result row click handler:**
       - Navigate to `/${orgSlug}/${result.id}` using `router.push`
       - Close dialog via `onOpenChange(false)`

       **On close (onOpenChange false):**
       - Clear query, results, error, highlightedIndex

       **Excerpt rendering:**
       - Create a `renderExcerpt` function that splits excerpt by `**` markers
       - Parts at odd indices (between `**...**`) render as `<strong className="font-semibold">{part}</strong>`
       - Parts at even indices render as plain `<span>{part}</span>`
       - Use `excerpt.split(/\*\*(.*?)\*\*/g)` for splitting

       **Dialog layout (per UI-SPEC):**
       - `DialogContent` with `className="p-0 max-w-xl mt-[10vh] gap-0"` — no default padding, positioned in upper-third
       - Remove the default close button from DialogContent (use `hideCloseButton` prop or override with empty DialogTitle for accessibility)
       - Add `aria-label="Search pages"` on the Dialog
       - Input area: `div` with `flex items-center gap-2 px-4 border-b` containing:
         - `Search` icon (16px, `text-muted-foreground`)
         - `Input` with `className="border-0 focus-visible:ring-0 h-11 text-sm"`, `placeholder="Search pages..."`, `aria-label="Search pages"`, `aria-autocomplete="list"`, autofocus
       - Results area: `div` with `role="listbox"` and `max-h-[352px] overflow-y-auto py-2` (8 rows x 44px = 352px)

       **States:**
       - **Idle** (query < 2 chars): show nothing below input (empty results area)
       - **Loading**: 3 `Skeleton` rows, each `h-11 w-full rounded-md mx-4 my-1`
       - **Results** (>= 1 match): list of result rows, each with:
         - `role="option"`, `aria-selected={index === highlightedIndex}`
         - `className="flex items-center gap-2 px-4 min-h-[44px] cursor-pointer hover:bg-muted"` + `border-l-2 border-primary bg-muted` when highlighted
         - Emoji (if present, 16px) or `FileText` icon (16px, `text-muted-foreground`)
         - Title: `text-sm font-semibold truncate`
         - Excerpt below title: `text-sm text-muted-foreground line-clamp-1` with renderExcerpt
       - **Empty** (0 matches, query >= 2): centered text `"No results for "{query truncated to 40 chars}"" + "Try a different word or phrase."`
       - **Error**: centered text `"Search unavailable. Try again in a moment."` with `text-muted-foreground`

    3. Update `src/components/workspace/sidebar.tsx`:

       **Add imports:**
       - `useState`, `useEffect` from `react` (useState may already be imported)
       - `Search` from `lucide-react`
       - `SearchPalette` from `./search-palette`

       **Add state:** `const [searchOpen, setSearchOpen] = useState(false)`

       **Add Cmd+K listener in Sidebar:**
       ```typescript
       useEffect(() => {
         function handleKeyDown(e: KeyboardEvent) {
           if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
             e.preventDefault()
             setSearchOpen(true)
           }
         }
         window.addEventListener('keydown', handleKeyDown)
         return () => window.removeEventListener('keydown', handleKeyDown)
       }, [])
       ```

       **Add Search button** between the brand header `<div>` and the first `<Separator />`:
       ```tsx
       <div className="px-2 py-1">
         <Button
           variant="ghost"
           className="w-full justify-start gap-2 text-muted-foreground"
           onClick={() => setSearchOpen(true)}
         >
           <Search className="h-4 w-4" />
           <span className="text-sm">Search</span>
           <kbd className="ml-auto text-xs text-muted-foreground">Cmd+K</kbd>
         </Button>
       </div>
       ```

       **Render SearchPalette** at the bottom of the Sidebar component (inside the fragment, after the toggle button):
       ```tsx
       <SearchPalette open={searchOpen} onOpenChange={setSearchOpen} />
       ```
