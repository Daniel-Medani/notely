    - Create unique org IDs: `const ORG_A = \`test-page-org-a-${Date.now()}\`` and `const ORG_B = \`test-page-org-b-${Date.now()}\``

    **Tests (describe: 'PrismaPageRepository - cross-tenant isolation'):**

    1. `findAll does NOT return pages from a different organization`:
       - Create a page in ORG_A via `prisma.page.create({ data: { organizationId: ORG_A, title: 'Org A Secret', order: 1.0, isDeleted: false } })`
       - `const repo = new PrismaPageRepository()`
       - `const results = await repo.findAll(ORG_B)`
       - `expect(results.filter(p => p.organizationId === ORG_A)).toHaveLength(0)`

    2. `findById does NOT return a page from a different organization`:
       - Create page in ORG_A, get its id
       - `const result = await repo.findById(page.id, ORG_B)`
       - `expect(result).toBeNull()`

    3. `findAllTrashed does NOT return trashed pages from a different organization`:
       - Create a page in ORG_A with `isDeleted: true`
       - `const results = await repo.findAllTrashed(ORG_B)`
       - `expect(results.filter(p => p.organizationId === ORG_A)).toHaveLength(0)`

    4. `findAllForOrg does NOT return pages from a different organization`:
       - Create a page in ORG_A with `isDeleted: false`
       - `const results = await repo.findAllForOrg(ORG_B)`
       - `expect(results.filter(p => p.organizationId === ORG_A)).toHaveLength(0)`

    5. `softDeleteMany does NOT affect pages in a different organization`:
       - Create page in ORG_A (isDeleted: false), get its id
       - `await repo.softDeleteMany([page.id], ORG_B)` — attempt to soft-delete from wrong org
       - Verify page in ORG_A still has `isDeleted: false` via `prisma.page.findUnique({ where: { id: page.id } })`
